# ТЗ: Мой женский календарь

## 1. Цель

Простое приложение для отслеживания менструального цикла. Главные критерии: понятный первый запуск, минимум действий для ежедневной отметки, спокойный визуальный стиль «цветение сакуры».

## 2. Платформа

- Flutter (Android, iOS)
- Локальное хранение, без аккаунта и без сети
- Язык интерфейса: русский

## 3. Цветовая гамма

Палитра цветения сакуры: кремовый фон, лепестки розового, глубокий цвет бутона как акцент, тёплая кора для текста, молодая зелень для фертильного окна.

## 4. Пользовательские сценарии

### 4.1. Первый запуск

1. Короткое приветствие.
2. Дата начала последних месячных.
3. Обычная длина цикла (по умолчанию 28 дней).
4. Обычная длительность месячных (по умолчанию 5 дней).

После этого сразу открывается главный экран.

### 4.2. Сегодня

- Номер дня цикла и текущая фаза.
- Сколько дней до следующих месячных (или задержка).
- Одна главная кнопка: отметить / снять месячные за сегодня.
- Быстрые отметки настроения.

### 4.3. Календарь

- Месяц, неделя с понедельника.
- Цветовые отметки: месячные, прогноз, овуляция, фертильное окно.
- Нажатие на день открывает карточку дня.

### 4.4. Карточка дня

- Месячные: да/нет.
- Интенсивность выделений.
- Симптомы и настроение.
- Короткая заметка.

### 4.5. Статистика

- Средняя длина цикла и длительность месячных.
- Список последних циклов.
- Оценка регулярности по последним циклам.

### 4.6. Настройки

- Длина цикла и длительность месячных (если истории ещё мало).
- Напоминание за день до месячных.
- Сброс всех данных.

## 5. Правила расчёта

- Цикл строится по фактическим дням месячных: подряд идущие дни — один цикл.
- Средние считаются по последним 6 циклам, если циклов меньше — по настройкам пользователя.
- Овуляция: длина цикла минус 14 дней от начала цикла.
- Фертильное окно: 5 дней до овуляции и 1 день после.
- Прогноз следующих месячных: дата начала последнего цикла плюс средняя длина.
- Это ориентир, а не медицинский диагноз.

## 6. Ограничения первой версии

- Нет облачной синхронизации.
- Нет графика базальной температуры и тестов на овуляцию.
- Нет медицинского заключения и рекомендаций по контрацепции.

## 7. Нефункциональные требования

- Основные действия доступны в 1–2 нажатия.
- Карточки крупные, подписи короткие.
- Данные не покидают устройство.
